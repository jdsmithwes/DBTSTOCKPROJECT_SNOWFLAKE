## Quick Start on Mac

### 1. Prerequisites Installation

```bash
# Install Node.js (required for Claude Code)
# Option A: Using Homebrew
brew install node@18

# Verify installation
node --version
npm --version

# Option B: Download from https://nodejs.org (LTS version)
```

### 2. Install Claude Code CLI

```bash
# Install Claude Code CLI globally
npm install -g @anthropic-ai/claude-code

# Verify installation
claude-code --version
```

### 3. Authenticate Claude Code

```bash
# Initialize Claude Code (first time only)
claude-code init

# You'll be prompted to paste your Claude API key
# Get it from: https://console.anthropic.com/account/keys
```

### 4. Clone/Setup This Project

```bash
# Navigate to your projects directory
cd ~/Projects

# Clone or create project (if using git)
git clone <your-repo-url> dbt-quant-analysis
cd dbt-quant-analysis

# Or create fresh directory
mkdir dbt-quant-analysis
cd dbt-quant-analysis
```

### 5. Start Claude Code in This Directory

```bash
# From your project root directory
claude-code

# This opens Claude Code terminal in your working directory
```

## Key Directories Explained

### `/dbt/models/`
- **staging/** → Raw data cleaning & standardization (no transformations)
- **intermediate/** → Business logic transformations
- **marts/** → Final tables for ML pipeline & analysis
- **tools/** → Data quality & diagnostic queries

### `/dbt/tests/`
- Ensure data accuracy before ML model ingestion
- Tests on uniqueness, nulls, row counts, and domain-specific rules
- Critical for hedge fund data governance

### `/scripts/`
All bash scripts should use Mac-compatible syntax:

```bash
#!/bin/bash
# Mac-compatible header (not #!/bin/bash -e)

# Use 'sed' with -i '' flag on Mac (not sed -i without quotes)
sed -i '' 's/old/new/g' filename

# Use 'gdate' for GNU date features (install via: brew install coreutils)
gdate +%Y-%m-%d
```

### `/config/`
Never commit credentials—use `.env` files:

```yaml
# dbt_vars.yml (template)
dbt_config:
  snowflake_warehouse: COMPUTE_WH
  cost_mode: "optimization"  # or "performance"
  backtest_lookback_days: 252
```

## Database & Cost Optimization

### Snowflake Configuration (profiles.yml)

```yaml
quant_hedge_fund:
  target: dev
  outputs:
    dev:
      type: snowflake
      account: [YOUR_ACCOUNT_ID]
      user: [YOUR_USER]
      password: [SET_VIA_ENV_VAR]
      role: TRANSFORMER
      database: DEV_ANALYTICS
      schema: dbt_dev
      warehouse: COMPUTE_XS  # Small warehouse for development
      threads: 4
      client_session_keep_alive: False  # Cost savings
      
    prod:
      type: snowflake
      account: [YOUR_ACCOUNT_ID]
      user: [YOUR_USER]
      password: [SET_VIA_ENV_VAR]
      role: TRANSFORMER
      database: PROD_ANALYTICS
      schema: dbt_prod
      warehouse: COMPUTE_L  # Larger warehouse for production
      threads: 8
      client_session_keep_alive: False
```

### Cost Optimization Principles

1. **Materialization Strategy:**
   - Staging models → `ephemeral` (zero cost)
   - Intermediate models → `view` or `incremental` (cheaper than full refreshes)
   - Marts → `table` (accessed frequently by ML models)

2. **Incremental Snapshots:**
   - Only process new data instead of full refreshes
   - Critical for daily pricing data

3. **Clustering Keys:**
   - Cluster by `symbol` + `date` for performance
   - Reduces scan costs significantly

## How to Use This with Claude Code

### Start a Session

```bash
# In your terminal
cd ~/Projects/dbt-quant-analysis
claude-code

# Claude Code terminal opens—you can now:
# - Run dbt commands: dbt run, dbt test, dbt debug
# - Edit files: create, modify, validate SQL
# - Execute bash scripts
# - Run Python analysis notebooks
```

### Claude Code Workflow Example

```bash
# 1. Debug a model issue
dbt debug

# 2. Run a single model
dbt run --select stg_raw_pricing_data

# 3. Run tests
dbt test --select stg_raw_pricing_data

# 4. Generate docs
dbt docs generate

# 5. Check data quality
dbt snapshot

# 6. Run full pipeline (production)
dbt run --profiles-dir ./config --target prod
```

### Claude Code File Operations (Mac equivalents)

```bash
# View DBT model
cat dbt/models/marts/ml_features.sql

# List all models
ls -la dbt/models/**/*.sql

# Find models by pattern
find dbt/models -name "*ml*" -type f

# Check file line count
wc -l dbt/models/marts/ml_features.sql

# Copy a model template
cp dbt/models/staging/stg_raw_pricing_data.sql dbt/models/staging/stg_new_data_source.sql

# Remove old test files
rm -rf dbt/logs/* dbt/target/*

# Set file permissions (for scripts)
chmod +x scripts/run_daily_pipeline.sh
```
